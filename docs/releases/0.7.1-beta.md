# 创作流 0.7.1 beta · 本地创作与内置协作管理

2026-11-21 更新，版本号保持 0.7.1 beta，替换此前同版本下载。

创作流以本地项目、任务与版本管理、视频审阅、修改意见、日历排期和桌面小组件为核心；需要团队共同审阅时，再使用公司局域网协作。

## 本次更新

- 协作管理器直接内置到创作流，从应用菜单或设置打开独立窗口，重复点击唤起已有窗口。
- 保留运行概览、空间与成员、员工接入中心、网络检测、存储与备份、存储用量、设置与维护七个页面。
- 员工配置接入沿用主窗口流程；管理本机服务时单独申请 Windows 授权，日常主窗口保持普通权限。
- 识别已有主机，沿用原程序和数据路径、成员、证书、容量和备份配置。主机电脑可同时参与客户端协作。
- 分别控制后台服务开机启动、登录后启动创作流、启动后打开管理窗口。关闭管理窗口不停止服务。
- 保留邀请码生成与重置、成员设备、连接检测、备份恢复、路径迁移、容量保护和卸载数据选择。
- 各意见界面支持视频时间码、创建时间、更新时间排序，正倒序、未完成优先和整体意见置顶。
- 审阅侧栏限制合理拖动宽度，排序控件保持单行；修复整体意见竖排，整体与时间点意见分区更清晰。
- 保留本地及协作版本删除和回收站、缩略图、按版本权限、离线同步、日历与小组件联动。

Windows x64 测试版，已在 Windows 11 验证。本次 GitHub 软件包由 Actions 从本次发布源码重新构建，文件散列以本发布附件为准。

## 更新已有软件和主机

先从系统托盘完全退出旧创作流和小组件，再更新服务器电脑及员工电脑上的创作流。仅本地用户无需部署主机，建议先导出本地备份；原始视频和图片需要另行备份。

已有公司空间：在服务器电脑打开内置管理器，识别或接管原服务。早期后台需要升级时，使用“升级现有主机”，先自动备份并沿用原目录；已配套的意见排序后台不需要因管理窗口集成而重复升级。

确认内置管理器正常后，可只卸载旧的“创作流协作管理器”软件，保留后台服务和公司数据。不要点击“卸载协作服务”，不要重新建立公司空间。原成员身份、视频和意见保留，无需重新发布。

## 验证范围

本地完成 50 项基础数据与同步检查、12 组内置管理窗口流程、13 组排序布局流程、14 组多人协作回归，以及免安装启动、打包资源、版本管理、窗口信任和备份迁移检查。授权与系统服务控制的界面自动检查使用隔离适配器，不等同于公司环境实测。

本机实际升级另已确认内置管理员窗口可用，旧管理器移除后服务持续运行、数据及证书保留，7 项网络检测通过。发布包不包含该电脑的部署记录或真实公司资料。跨电脑连接、不同编码与多显示器仍需在使用环境测试。

本次 CI 重新执行基础测试、服务端测试和打包资源检查；不会冒称重新执行全部本地界面验证。
