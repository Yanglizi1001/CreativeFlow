# 统一颜色设置

排期颜色以任务为单位独立保存。新任务优先分配未使用的预设色，“恢复默认颜色”恢复该任务建立时的颜色。项目详情中的“项目标识颜色”仅用于项目目录和甘特汇总条，不控制任务条。beta.4 中跟随项目的任务升级时固化当前显示颜色，已有独立颜色保持不变。

点击日历月视图、周／日计划或甘特图的任务条，直接打开对应任务详情，颜色入口位于任务名称下方。项目详情的任务列表也提供独立色块，改色不触发跳转；点击任务名称打开任务详情。任务详情可查看项目，返回则回到原任务；当日计划也能进入任务详情并返回原日期列表。所有详情操作保留日历日期与位置。

日历月视图、周／日列表、甘特与小组件共享同一排期颜色。颜色选择器提供十二个预设色、系统色板、HEX 输入、即时预览、恢复默认。深浅背景自动选择文字颜色；白色条带也保留细边框。蓝色焦点及选中状态不随业务色更改。

项目状态、类型、阶段、版本状态各自有颜色映射。同名的“进行中”项目状态与版本状态可以使用不同颜色。下拉菜单颜色按钮与选中词条是两个独立操作；修改颜色不会选中其他状态。设置中的“标签与颜色”包含内置、自定义及实际使用中的词条，并可恢复全部标签默认颜色；此操作不修改项目与任务的排期颜色。

选色面板使用独立浮层，保持在窗口内且高于下拉菜单、详情和弹窗。预设色直接应用；色板与 HEX 先预览，再点应用或回车。非法 HEX 显示说明。Esc 或点击空白取消未应用的草稿，Esc 优先关闭选色面板，再关闭下拉菜单和详情。

颜色保存在现有数据库中，跨窗口同步，随完整 JSON 备份导出和恢复。旧备份自动兼容。颜色功能包含在重新编号后的 0.7.0-beta.2 更新测试版中。

验证：`npm run test:colors` 覆盖任务独立颜色、beta.4 迁移、自动分配、对比度与备份结构。原生窗口交互验证覆盖日历与甘特任务详情、项目快捷改色、详情返回、改色不切状态、Esc、菜单层级、小组件同步、重启、备份与旧数据保色，以及 860×650 窄窗口的任务详情与选色面板。

任务独立颜色与日历详情入口调整已包含在 0.7.0-beta.2 更新测试版中。本版来自原 beta.5 的重新编号，功能没有回退。
