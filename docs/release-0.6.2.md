# 创作流 0.6.2

- 月历使用 22px 高的连续彩色任务条，仅显示名称。完整项目、任务、日期及阶段可悬停查看。
- 从任务开始日期持续到截止日期；未填写任务开始日期时使用项目开始日期，两者均未填写时保留截止日标记。
- 跨周、跨月的条幅分段接续。任务颜色按标识稳定分配，切换月份不变。
- 每周保留三个展示轨道；被隐藏的任务按日期汇总到“还有 X 项”，点击显示当天完整任务列表。
- 当日计划按周期筛选当天进行中的任务，保留点击条幅查看详情、点击日期空白处查看当日列表。
- 固定当日计划中项目、任务与辅助信息图标的尺寸与对齐，避免拉伸变形。
