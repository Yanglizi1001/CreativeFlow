# 创作流 0.6.3

- 路径导航统一由主工作区外壳管理，不再分散在各页面内容或审阅标题栏内。
- 所有模块使用固定 40px 高导航行，导航首项距主工作区左侧 24px；内容独立滚动，导航位置保持稳定。
- 项目总览、项目详情、任务工作区、审阅中心、项目内审阅与审阅任务保持相同坐标；今日、日历、修改意见、设置也使用统一导航行。
- 路径父级可点击，当前层级使用统一强调样式；长名称省略显示，悬停显示完整名称。
- 内容区与标题栏统一水平间距；调整目录宽度时导航跟随工作区边界，滚动或展开详情不会引起导航漂移。

验证覆盖各模块导航坐标、父级跳转、实际长列表滚动、长项目名称、详情抽屉、侧栏拖拽和窄窗口；并回归连续月历、甘特图、视频缩略图、小组件同步与审阅操作。使用独立测试数据。
