# 创作流 0.7.1 beta · 局域网协作与版本管理

在 0.7.0 beta3 本地版基础上整合公司局域网协作，保留本地项目、视频审阅、排期与桌面小组件的工作方式。

## 新功能

- 本地与公司空间切换，本地项目上传资料后仍保留原项目。
- 按版本发布协作视频，显示创建者与发布者；缩略图随发布、替换与重启更新。
- 每个版本设置不可见、仅查看、可批注、可编辑与可管理权限，主机校验读取及修改。
- 意见、完成状态、排期与小组件同步；离线修改持久保存，重连后继续同步，同字段冲突对比后处理。
- 审阅工作区、中心预览与任务详情统一删除版本；本地与协作回收站恢复视频关联、意见与权限。
- 协作删除要求联网和管理权限；新增意见后重新确认，删除最后版本保留任务与排期，编号递增。
- 图形管理器集中安装、升级、邀请码、成员设备、网络检测、接入文件、备份恢复、迁移及卸载数据选择。
- 服务与管理器自启分别控制；空间容量和磁盘余量保护，回收站视频受清理保护。
- 员工导入 .cfspace 后在应用内确认主机信任，无需手工安装 Windows 根证书。

## 下载与更新

完整包 CreativeFlow-Full-0.7.1-beta-win-x64.zip 包含客户端与管理器的安装版、免安装版、独立主机运行环境、离线维护工具及说明书，也可分别下载四个程序。SHA256SUMS.txt 用于核对完整性。

已有公司空间：先更新管理器，在“设置与维护”执行“升级现有主机”，沿用原目录并自动备份；再完全退出旧客户端、托盘及小组件后更新客户端。保留原公司空间、身份与视频，无需重新上传。不要卸载服务或重新建立空间。仅本地用户只需更新客户端，建议先导出备份。

Windows x64 测试版，当前验证环境为 Windows 11。管理器需要管理员授权，内含独立运行环境；后台服务不依赖管理器窗口一直打开。

## 验证范围

本地完成 44 项数据／同步检查、41 项服务端检查，真实打包客户端八组版本管理交互、13 组多人协作回归，以及缩略图、容量、管理器和窗口信任验证。使用独立临时空间，不操作真实公司资料。

本发布由 GitHub Actions 从标签对应源码重新构建，自动测试与本地界面验收分开记录。实际跨电脑网络、不同视频编码、缩放与多显示器仍需在部署机器测试。
