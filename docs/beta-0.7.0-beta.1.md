# 创作流 0.7.0-beta.1

Windows 11 x64 公开分发测试版。标题栏与设置中均标注 Beta，安装包和免安装程序的文件名包含完整版本号。

## 示例项目

新用户首次启动只有一个「示例项目 · 新品发布创意全案」。项目包含六个任务，展示视频、图片、PPT、自定义脚本类型，以及策划、修改、内部审核、客户审核、已交付等阶段。

主宣传片包含两个版本和自检、内部审核、客户反馈清单。内置原创 18 秒视频、示例封面，支持直接播放、时间码定位、缩略图和系统打开。PPT 与脚本任务保留空版本，便于练习关联自己的文件。项目说明提供体验步骤。

排期按首次启动当天生成，覆盖今天、本周和后续日期。已有用户数据不会被替换成示例。

## 本轮修复与验证

- 审阅上一条、下一条导航包含无时间码意见；此类意见只选择对应行，不跳转播放位置。
- 修复切换关联文件时播放器状态残留；内置演示视频的已知时长得到保留。
- 本地数据库进行结构检查；无法识别时保留原始记录并提供导出入口，导入备份拒绝非法时间码类型。
- 验证单示例首次启动、视频及图片素材、版本继承与删除、意见撤销、日历与甘特图、跨任务意见中心、小组件同步、重启保存、备份导入导出、旧数据保留、异常数据恢复和导航布局。

## 测试范围与限制

已在当前 Windows 环境进行自动交互和视觉检查；仍需其他电脑的屏幕缩放、不同视频编码、文件路径和长期使用测试。内置播放器不支持的编码可调用系统播放器。备份包含项目记录，用户自己关联的原始素材需单独复制。
