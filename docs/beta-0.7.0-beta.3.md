# 创作流 0.7.0-beta.3 · 审阅与桌面小组件交互更新

面向 Windows 11 64 位的测试版，版本号保持 **0.7.0-beta.3**。

## 桌面小组件

- 双击修改意见文字，在原位编辑；保存后与项目、审阅及修改意见中心同步，保留所属版本、时间标记和完成状态。
- 支持多行文字、Ctrl+Enter 保存、取消和 Esc；切换条目、标签页、折叠分组或关闭小组件时，可保存、放弃或继续编辑草稿。
- 右上角新增置顶按钮，开启后位于普通窗口前方，关闭后可被其他窗口覆盖；重新打开或重启后记住选择。
- 支持共享撤销与重做历史；跨窗口同时编辑、原意见被删除时提示处理，保留未提交草稿。

## 审阅与版本

- 审阅工作区及审阅中心可直接新增版本，可关联新视频、选择继承来源并继承未完成意见。
- 点击意见正文打开编辑区，支持多行、右键编辑或删除、列表聚焦时 Delete 删除，以及撤销重做。
- 增加「整体意见」，用于不绑定时间点的反馈；与时间点意见可以转换，整体意见不生成时间线标记。
- 编辑区提供取消、Esc、Ctrl+Enter；切换页面、版本或关闭意见栏前保护未保存内容。

## 统一交互

- 应用菜单集中到标题栏「创作流 ▾」，包含创建、撤销重做、备份、窗口及设置入口。
- 最小化、最大化/还原、关闭采用统一图标与按钮尺寸，并同步实际窗口状态。
- 今日、日历、甘特可直接创建任务或项目，按当前上下文预填；创建所属项目后可返回任务草稿。
- Ctrl+Z 撤销、Ctrl+Shift+Z 重做，主窗口与小组件共用历史；输入文字时优先使用文字编辑的撤销。
- 修复意见逐字保存导致撤销过细、备注显示不同步、备份未包含刚提交内容，以及窄窗口编辑按钮不可见等问题。

## 一个示例项目，上手体验

首次使用只显示一个「示例项目 · 新品发布创意全案」，包含六项任务、V1/V2 版本、18 秒内置视频、封面图片、自定义标签、不同来源的修改清单，以及整体和时间点意见。示例日期随首次启动日期生成，便于查看当日计划和连续排期。

建议依次体验：展开项目 → 进入主宣传片任务 → 审阅视频和客户反馈 → 编辑或新增整体意见 → 新增版本并继承未完成意见 → 查看日历/甘特 → 打开桌面小组件编辑并观察同步 → 尝试撤销重做及导出备份。

分发内容仅含示例及演示素材，不包含个人项目、备份或本机设置。已有用户更新后继续读取原有项目；如需体验示例，先导出备份，再在设置中恢复示例数据。

- 免安装版：`CreativeFlow-0.7.0-beta.3-win-x64.exe`，双击运行。

打开新版前，请先从系统托盘退出旧程序。换电脑时需另外复制原始视频、图片等素材；JSON 备份不包含原始素材。

撤销最多保留本次运行中的 50 次工作数据操作，并有容量上限；播放、筛选、导航不进入历史。新修改会清空重做分支；重启、导入备份或恢复示例会清空历史。
