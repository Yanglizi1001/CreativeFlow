# 创作流 0.7.1 beta 版本管理更新说明

适用批次：2026-11-20-version-management。

## 升级顺序

1. 公司服务器：关闭旧管理器，安装或运行本完整包中的新版协作管理器。识别现有主机后，在“设置与维护”点击“升级现有主机”。沿用原服务器程序目录与协作数据目录，升级前自动完整备份。不要卸载协作服务或重新建立空间。
2. 员工电脑：完全退出客户端、托盘及小组件，再安装或运行新版客户端。安装版和免安装版任选一个。
3. 打开原公司空间检测连接。原成员身份、证书、项目、视频、意见和容量配置继续使用；本次无需重新上传视频。仅更新客户端而未升级服务时，协作回收站接口会提示主机需要升级。
4. 仅使用本地项目的电脑只需更新客户端。

## 删除版本

- 视频审阅页：点击“版本操作 → 删除当前版本”。
- 审阅中心：选中任务与版本，在展开的预览区域点击“版本操作 → 删除当前版本”。
- 项目任务详情：点击版本栏中的“删除版本”。三个入口共用相同的确认窗口。
- 确认窗口显示所属项目、任务、版本、意见列表数、意见总数及未完成数。取消不会改变数据。期间新增意见或版本内容变化，需要重新核对再确认。
- 未保存的意见须先保存或取消；本机小组件、任务详情中有该版本未提交草稿时，也会阻止删除并提示。视频正在发布时等待完成再删除。
- 本地删除移入回收站，支持 Ctrl+Z 撤销；回收站退出软件后仍保留。协作删除须联网且完成待同步修改和冲突处理，主机确认成功后才显示已移入回收站，不排入离线队列。

## 权限及删除后行为

- 本地版本由当前电脑用户管理；协作版本仅“可管理”成员可删除或恢复。上传者身份本身不额外授予删除权。仅查看、可批注、可编辑不能删除。
- 删除正在审阅的版本后切换到最新的剩余版本；删除其他版本不打断当前审阅。
- 删除最后一个可见版本后保留任务与日历排期，显示建立版本入口。只有任务管理者可建立新版本。
- 同事正在播放的版本被删除后，会停止播放并提示删除人；未提交草稿保留本机，可在协作同步中心导出。版本编号不因删除最高版本而回退，例如删除 V3 后，下次默认 V4。

## 恢复版本与视频占用

1. 在审阅“版本操作”或应用菜单打开“版本回收站”。也可从“项目归档与回收站”进入。
2. 找到版本，核对项目、任务、删除时间及删除人，点击“恢复版本”。
3. 恢复版本内容、视频关联、意见、完成状态及原成员权限。仅恢复同次删除的意见，不恢复更早独立删除的意见。成员当前身份及管理权限会重新核对。
4. 所属项目或任务已删除时，先恢复父级；本地父级删除可在本次会话使用撤销，或从本地备份恢复。存在同名版本时先重命名现有版本。
5. 本地原视频与共享盘文件不会因删除版本而删除。协作视频在回收站保留时仍占容量，管理器不会把仍有版本或回收站引用的视频当作无引用文件清理。永久清理由管理员在存储用量中按可清理范围单独确认。
