# 创建流程、应用菜单与撤销重做

本说明对应 0.7.0-beta.3 交互优化版，基线为 0.7.0-beta.2。新程序独立打包，旧版安装包和已发布标签保留。

## 创建入口

| 位置 | 入口和完成后的行为 |
| --- | --- |
| 项目总览 | 新建项目后打开项目详情 |
| 项目详情、目录 | 新增任务归入明确选择的项目 |
| 任务工作区 | 新增版本后切换到新版本 |
| 审阅工作区 | 新增版本、选择文件和继承来源；保留在审阅工作区 |
| 审阅中心 | 展开任务后新增版本，仍留在中心；可选择进入审阅 |
| 今日 | 新增任务默认今天；没有明确项目时由用户选择 |
| 日历、甘特 | 新增任务默认当前选定日期；项目详情上下文或当日唯一项目可预填项目 |

任务创建表单可切换到新建所属项目，再返回原任务草稿。独立创建的所属项目会立即保存；取消任务不会删除这个已经创建的项目。其他创建窗口取消不会生成任务或版本。

版本编号按任务中现有最大编号递增，允许改名并拒绝重复名称。默认空版本；开启继承后明确选择来源版本，只复制未完成意见并生成独立记录。文件选择、版本和意见继承合为一次创建操作。

## 统一菜单

应用菜单固定在内容导航行左侧，不占用系统标题栏；撤销/重做与返回在同一行。菜单按创建、编辑、数据、窗口与应用分组，支持方向键、Enter、Escape、点击外部关闭，窄窗口中内部滚动。

新增版本只针对明确打开的任务启用。没有可撤销/重做记录时对应入口置灰，提示下一步的具体动作。设置与菜单共用备份逻辑。

## 撤销与重做规则

- Ctrl+Z 撤销，Ctrl+Shift+Z 重做；输入框中保留原生文字撤销，不回退项目数据。
- 弹窗未提交内容不触发外部数据撤销。
- 勾选、编辑、导入意见，项目/任务/版本/清单的增删及信息、标签和颜色修改进入历史。
- 批量导入和复合版本创建各记一次；反馈编辑结束后保存一次，不逐字入历史。
- 页面跳转、筛选、窗口尺寸、播放/定位/倍速与播放元数据不占历史，也不清空重做分支。
- 撤销后发生新的工作数据修改，清空重做分支。
- 主窗口与小组件在同一应用会话中共用历史，Web Locks 串行处理修改以避免覆盖。
- 以实体 ID 恢复内容，关联原始文件不被修改或删除。撤销不回退无关播放位置和近期活动。
- 最近最多 50 次操作，历史有容量限制；过大操作不被记录时明确显示状态提示。
- 重启清空历史并保留工作数据；备份导入与恢复示例清空历史，执行前有提示。
- JSON 备份仅包含工作数据，不带撤销历史；导出等待刚提交的编辑保存完成。

## 验证

`pnpm test` 运行颜色、迁移和工作数据补丁测试。原生 Electron 示例配置用于验证创建、撤销/重做、文字编辑、批量导入、删除恢复、跨窗口同步、重启、备份和窄窗口布局，不接触用户日常项目。
