# 桌面窗口行为（更新测试版）

最小化按钮正常收起到 Windows 任务栏，不隐藏到托盘。

主窗口标题栏关闭、系统关闭（包括 Alt+F4）共用主进程关闭处理。默认显示原生选择框：取消、隐藏到托盘、退出应用。勾选“不再提醒，记住本次选择”后，隐藏对应 closeToTray=true，退出对应 false，同时 askBeforeClose=false；不勾选或取消时不改变设置。cancelId=0 使 Esc 等同取消。

设置“桌面行为”提供两个开关：点击关闭时隐藏到系统托盘、关闭前询问。它们与关闭选择使用同一份本地 desktop-preferences.json，并通过事件实时同步。偏好原子写入，失败提示并恢复 UI；重复点击关闭只保留一个询问。

托盘菜单退出明确跳过询问，退出前要求所有窗口提交正在编辑的输入；小组件关闭保持独立。项目数据与关闭偏好分别保存，偏好不写入项目备份。

验证覆盖任务栏最小化、取消/Esc 映射、临时隐藏与退出、两种记忆选择、设置同步、重启保留、重新开启询问、重复关闭防抖、退出保存与小组件独立关闭。

本次仅修改和验证代码，未生成安装包或测试分发包。
