# 创作流 0.7.0-beta.2 · 更新测试版

本版为原 0.7.0-beta.5 的重新编号版本，功能未回退。发布文件只保留本版与 0.7.0-beta.1 首测版。

## 主要更新

- 统一柔白石墨界面、路径导航、返回、列表交互、详情及窗口布局。
- 任务颜色独立保存，日历任务条直接打开任务详情；项目任务列表支持快捷改色，任务与项目详情之间可返回。
- 状态、类型、阶段和版本状态支持自定义颜色，日历、甘特与小组件同步。
- 审阅项目与项目目录共用可收起、展开、拖拽调整的侧栏，保留任务、版本和播放位置。
- 最小化到任务栏；关闭可选择隐藏到托盘或退出，支持记住选择与设置同步。
- 保留已有数据、旧备份兼容以及首次启动的单个示例项目。

## 使用

Windows 11 64 位。安装版运行 `CreativeFlow-Setup-0.7.0-beta.2-win-x64.exe`；免安装版运行 `CreativeFlow-0.7.0-beta.2-win-x64.exe`。

本机已有创作流时先从托盘退出旧程序，再启动本版。更新前可在设置中导出备份；原始素材文件需单独保存和复制。

已完成任务设色、详情返回、侧栏收起、宽窄窗口布局、视频播放、保存、同步及备份检查。其他电脑的视频编码、文件路径与缩放比例仍需测试。
