# 柔白石墨 · 统一界面与交互

## 视觉约定

以已确认的 A 方向为基础。标题栏和侧栏采用近白灰色，白色工作区承载主要内容，石墨色为主操作按钮。蓝色仅用于焦点、链接、活动指示线、少量信息提示。状态与阶段仍使用具有语义的彩色圆角矩形。

`src/design-system.css` 为最后加载的共享视觉规范，统一颜色、圆角、间距、字号、按钮、表格、表单、菜单与抽屉；旧布局文件继续承担已有模块的结构规则。新增视觉元素优先使用该文件中的共享变量，不另建独立配色。

- 标题栏 43px；系统窗口操作保留在右上角，返回按钮不进入标题栏。
- 路径栏固定 40px，内容左边距 24px，右侧为固定宽度返回区域。
- 操作按钮高度 32px、圆角 7px；状态标签圆角 4px，不使用圆形状态图标。
- 深色主按钮用于创建、进入审阅、添加意见等当前操作；删除使用低强调红色次级按钮，确认删除使用红色主按钮。
- 详情、设置、弹窗、播放器辅助区域、小组件沿用同一套灰色层次与控件。

## 交互约定

- 主导航切换模块并进入模块首页；侧栏目录直接进入对应项目或任务。
- 项目任务表与审阅任务表单击选中并展开，重复单击不收起；双击或明确的进入按钮进入工作区。
- 项目和审阅列表默认显示最新版本，版本选择器手动切换；版本不再作为路径层级。
- 路径可跳转上级，返回可回到来源；切换侧栏内容保存来源位置，重复打开当前页不增加无意义历史。
- 详情按需打开，关闭按钮、Esc、点击遮罩关闭；下拉菜单高于详情与其他表单，Esc 优先关闭菜单。
- 下拉菜单支持方向键、Home、End、Enter 和 Esc，选择后焦点回到触发按钮；自定义标签保留文本输入与回车创建。
- 全局搜索 Esc 或点击工作区关闭。按钮、开关、侧栏收起和窗口操作具有可读名称与键盘焦点。
- 审阅保留一处意见输入区；上一条与下一条作为不可拆开的按钮组，空间不足时整组换行。
- 1060px 及以上窗口优先保持视频与意见并排，较小窗口采用可滚动的上下布局，视频限制高度，意见保持可见尺寸。
- 日历日期空白打开当日计划，任务条打开详情；区间条跨周连续、限制三条轨道并显示剩余数量。甘特与月历使用相同任务色和日期继承规则。
- 最小化、关闭询问、记住选择、设置同步、托盘恢复与退出保持既有约定。
