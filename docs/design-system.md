# 创作流 0.6.0 交互与视觉规范

## 视觉基准

- 主应用：`design/core-workspace-windows11-v3.png`
- 小组件组合：`design/windows11-desktop-widgets-v1.png`
- 月、周、日状态：`design/windows11-plan-widget-states-v1.png`

## 核心令牌

- 字体：Segoe UI Variable、Segoe UI、Microsoft YaHei UI
- 主色：`#176BFF`
- 主文本：`#101624`
- 次文本：`#66748C`
- 边框：`#D9E0E9`
- 主画布：`#FFFFFF`
- 冷灰表面：`#F5F8FC`
- 深色 Mica 侧栏：`#1D2A3C`
- 控件圆角：6px；状态标签：5px；内容面板：8px
- 小组件圆角：12px

## 容器和组件

- 主应用：固定导航、可调宽项目目录、主工作区；详情按需以右侧抽屉打开。
- 修改意见使用版本下的动态标签页和平铺清单，不进入单条详情页。
- 小组件采用项目计划与修改意见标签切换，背景透明，独立悬浮窗口。
- 主日历支持月网格、周列表、日列表；小组件月、周、日均使用列表。

## 核心交互

- 修改清单标签可切换和新增。
- 修改意见可勾选、筛选、排序和快速录入。
- 月、周、日计划可以切换，任务可直接完成。
- 小组件与主工作区复用相同的交互语言。

## 信息层级

- 项目 → 任务 → 版本 → 修改清单 → 修改意见。
- 项目状态、任务阶段、版本状态分别维护；完成修改意见不会自动完成版本。
- 项目路径：项目 → 项目名称 → 任务名称；版本通过下拉选择。
- 审阅路径：审阅中心 → 项目内审阅任务 → 任务名称；版本通过下拉选择。
- 目录点击导航；任务表单击展开，双击或“进入任务”进入工作区。
- 返回上一页与路径导航区分：前者回到来源页面，后者进入明确的父层级。
- 列表筛选、排序和滚动位置在切换页面后保留。

## 编辑、删除与保存

- 详情字段直接编辑，备注失焦自动保存；最近动态记录真实操作。
- 项目、任务、版本、清单支持删除，确认说明删除范围；磁盘原文件保留。
- 单条意见删除提供 10 秒撤销；允许零项目、零任务、零版本并显示空状态。
- 弹窗使用统一层级与焦点约束；Esc 只关闭最上层；下拉菜单浮在抽屉和表格之上。
- 数据本地持久保存，保存失败明确提示；小组件和主窗口同步数据。

## 审阅

- 每个视频任务显示一个版本，默认最新版本；历史版本可手动选择。
- 使用真实本地视频时长与播放信息，无文件或无法解码时显示明确提示。
- “添加修改意见”展开输入区，暂停视频并带入当前时间码；清单与任务工作区共用数据。
- 时间轴标记定位意见，支持上一条 / 下一条未完成意见和当前位置附近循环。
- 小窗口下播放器与意见区纵向排列，表格保留横向滚动。
