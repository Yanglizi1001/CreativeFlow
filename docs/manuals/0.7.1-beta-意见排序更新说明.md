# 修改意见排序使用说明

适用版本：0.7.1 beta；交付批次：2026-11-21-opinion-sorting。

## 在哪里设置

任务详情的修改清单、视频审阅右侧、修改意见中心、桌面小组件的修改意见页都有“意见排序”。审阅中心预览跟随审阅页的排序。

| 排序方式 | 用途 |
| --- | --- |
| 原始顺序 | 保持清单原有排列，适合逐条核对导入清单 |
| 视频时间码 | 按实际视频秒数从前到后或从后到前处理 |
| 意见创建时间 | 查找新提出的意见，可切换最新或最早优先 |
| 最近修改时间 | 查找正文、时间码最近改过的意见，可切换方向 |

“未完成优先”可独立勾选；“仅看未完成”仍是单独的筛选条件。点击“重置”恢复当前界面的默认排序。

任务详情默认原始顺序；审阅默认视频时间码从前到后；修改意见中心和小组件默认创建时间最新优先。每个界面分别记忆，个人项目和各公司空间也分别记忆，重启软件后保留。仅查看成员也可以设置自己的排序，不会修改清单原始顺序、产生同步操作或改变同事的界面。

## 视频时间码与整体意见

时间码按数值比较，例如 02:00 在 01:01:00 之前。“整体意见”独立成组，可以折叠，也可以取消“整体意见置顶”让它放在后面。00:00 表示视频开头，不会被视为整体意见。

修改意见中心保留项目、任务和版本边界，同版本各清单的意见一起排序，并在每条意见下显示来源清单。不同视频版本的时间码不会混排。小组件也按各版本分别排序。

审阅页的“上一条未完成”“下一条未完成”按所选顺序遍历当前版本的未完成意见，必要时自动切换所属清单、展开整体意见。视频进度条上的标记始终按照视频时间定位。

## 编辑和同步

编辑期间排序入口暂时不可用，已有行保持位置，新的同步意见等编辑结束后再按顺序展示。正文、时间码修改会更新最近修改时间；勾选完成仅记录完成状态变化，不会把意见变成“刚刚修改”。离线新建与编辑保留本机操作时间，连接后一起同步。

旧意见未记录创建时间时显示“时间未记录”，在时间排序中置后。升级不会替旧数据编造创建日期。时间相同时保持稳定排列。鼠标停在意见上可查看完整的创建和修改时间。

文本导入记录导入时间；新版本继承未完成意见时创建新的意见时间，并保留来源信息；从版本回收站恢复保留原时间。直接上传本地项目保留已有时间，无时间的历史意见继续标记未记录。旧数据导入或升级前建议保留原始备份。

## 升级步骤

仅本地使用：完全退出旧软件，更新客户端安装版，或运行新版免安装版。

公司协作：先更新协作管理器，在“设置与维护”选择“升级现有主机”，沿用原公司空间和路径；再更新员工客户端。管理器已内置新版主机服务与离线运行环境。无需卸载协作服务、重新创建公司空间或重新导入证书。只更新管理器界面不会自动升级现有服务。

## 验证范围

本批次验证基础排序与时间记录、实际 Windows 软件窗口、安装包中的客户端、双用户权限、离线冲突处理、小组件、版本删除与恢复。测试使用临时示例空间，不修改公司已部署服务。公司实际跨电脑网络接入仍需在部署环境检查。
