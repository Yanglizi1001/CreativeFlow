# 审阅布局优化说明

适用批次：2026-11-21-opinion-layout；产品版本：0.7.1 beta。

本次调整客户端界面，协作管理器和主机服务沿用 2026-11-21 意见排序批次。已经升级过该批次主机的用户，只需完全退出创作流客户端后更新客户端，不需要再次升级或重启协作服务。完整包中的管理器用于新部署或尚未完成此前主机升级的机器。

## 排序工具条与侧栏

审阅侧栏默认宽度 600 像素，可拖动范围 560–720 像素。上限同时根据可用空间收缩，为播放器保留至少 320 像素；双击分隔线恢复默认宽度。旧版本保存的过窄或过宽设置会自动限制到新范围。

排序方式、方向、未完成优先、整体意见置顶和重置固定在同一行。编辑保护和保存提示显示在工具条下方，避免挤压操作按钮。

窄窗口会自动收起左侧项目导航，增大窗口后恢复原有展开状态。空间仍不足以并排显示时，播放器与意见区自动上下排列，整页可纵向滚动，不挤压意见区。上下排列时隐藏左右拖动分隔线。

小组件最低宽度同步调整为 560 像素，默认宽度保持不变，确保排序操作不被截断。

## 整体意见与时间点意见

按视频时间码排序时，整体意见使用浅紫色底、边框和左侧强调线组成独立区域。标题横向显示数量和“针对整部视频”说明；时间点意见使用独立标题，并标注“按视频位置处理”。00:00 仍是视频开头的时间点意见。

“整体意见置顶”决定整组位于时间点意见之前还是之后，取消置顶也不会混入时间点意见。整体意见可以点击标题或通过键盘折叠，审阅的上一条、下一条未完成导航会在需要时自动展开该组。

编辑意见期间禁用排序和分组折叠，保留当前输入与行位置。保存或取消后恢复。已完成、选中、悬停状态与分组底色分别呈现，不以颜色单独表示分组。

任务清单、视频审阅、修改意见中心和桌面小组件使用相同分组结构。其他时间排序、原始顺序、筛选、同步和权限规则保留。仅整体意见、仅时间点意见和空清单都有相应显示，不保留空分组标题。
