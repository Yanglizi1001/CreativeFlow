# 创作流 0.6.1

- 版本文件缩略图保持固定比例、居中；关联视频后自动截取画面，项目列表、文件区、审阅列表和展开预览共用缩略图。
- 月历每格展示两条紧凑任务，多余内容通过“还有 X 项”打开当日完整计划，内容限制在日期格内。
- 新建与详情支持项目、任务开始日期。开始日期不得晚于截止日期；任务超出项目周期时可确认扩展周期。
- 日历新增甘特视图，项目和任务按周期展示；支持展开折叠、周/月缩放、日期导航、今天线、周末背景和详情跳转。
- 旧记录未设开始日期时显示截止日标记，不推测历史起始时间。
- 小组件计划按项目周期与当前日/周/月重叠筛选，按项目、任务分组，并标注未完成的逾期项目。
- 小组件意见按项目、任务分组，意见注明版本和清单来源；支持折叠及完成划线，与主窗口同步。
- 审阅的上一条与下一条未完成按钮固定为同一组，窄窗口整组换行。

验证涵盖密集日历、实际视频缩略图、日期编辑、甘特行与详情、小组件周期筛选与分组同步、窄窗口按钮布局。使用独立测试数据，不改变现有用户项目。

视频缩略图取决于本机内置解码能力；文件丢失或格式不支持时保留文件类型图标。
